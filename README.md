# ![Application Icon for JPEdit](./assets/edit.svg) JPEdit

A simple editor for simple needs.

This editor is a fork of the classic-inspired [MS-DOS Editor](https://en.wikipedia.org/wiki/MS-DOS_Editor) homage. The goal is to provide an accessible editor that even users largely unfamiliar with terminals can easily use.

## Features

- **Classic Feel**: Inspired by the 90s DOS editors.
- **Word Processor Mode**: Fixed column width word wrap and centered text layout.
- **Distraction-Free Mode**: Press `F11` to hide toolbars and margins.
- **Theming**: Support for multiple classic and modern color schemes.
- **Modern Controls**: Standard keyboard shortcuts (Ctrl+C, Ctrl+V, Ctrl+S, etc.).
- **Cross-Platform**: Works on Windows, Linux, and macOS.
