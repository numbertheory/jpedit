# Available Themes

You can configure the appearance of `jpedit` by setting the `"theme"` key in your `settings.json`.

## Themes

The following themes are available:

| Theme Name | Description |
| --- | --- |
| `"default"` | The default theme, matching Windows Terminal's Ottosson palette. |
| `"classicblue"` | Classic solid blue background with bright white text. |
| `"classic"` | Retro green-on-black terminal look. |
| `"paper"` | Dark grey text on an off-white background. |
| `"solarized-dark"` | Low-contrast theme with a teal/blue base. |
| `"gruvbox-dark"` | High-contrast theme with warm earth tones. |
| `"nord"` | Arctic-inspired cool blue-grey palette. |
| `"monokai"` | Vibrant high-contrast theme. |
| `"dracula"` | Popular dark theme with purple and pink accents. |
| `"everforest-dark"` | Comfortable green-based dark theme. |

## How to Set

Open your `settings.json` and add or update the `"theme"` key:

```json
{
    "theme": "classicblue"
}
```

The editor will automatically reload the theme when you save the settings file.
